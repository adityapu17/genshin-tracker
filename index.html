Hubungkan akun HoyoLab kamu. Cookie disimpan lokal di HP ini saja, tidak dikirim ke server manapun selain HoyoLab.

Cara ambil Cookie HoyoLab

  1. Buka hoyolab.com di browser HP/laptop, login ke akunmu.
  2. Buka DevTools (F12) → tab Network. Reload halaman.
  3. Klik salah satu request ke bbs-api-os.hoyolab.com.
  4. Di bagian Request Headers, cari baris Cookie, copy semua isinya.
  5. Paste ke kolom Cookie di app ini.

Kalau di HP susah buka DevTools, pakai browser laptop dulu buat ambil cookie-nya, lalu paste manual ke app di HP.
